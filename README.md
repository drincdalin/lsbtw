# lsbtw

lsbtw is a file lister just like the ls command in linux, but it s rewritten in *C*. you can put it in any folder you want and it will output whatever files you have in that dir.

## how to compile
you must have gcc compiler installed on your machine. then, in your folder containing the code run <br> `gcc -o lsbtw ls.c` or whatever name you want.

## how to use
1stly, run ./lsbtw in wtv folder you want to (the program needs to be in the same directory), then on the arguments type `-a` to show all files (including dotfiles) or leave blank for standart file output.
